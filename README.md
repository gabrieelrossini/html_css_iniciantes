## Estrutura do Projeto

| Pasta | Tópico | Principais Conceitos |
|-------|--------|---------------------|
| `bikcraft-exercicio` | Site completo: Header, Main, Features, Footer, Flexbox, Grid, Responsivo |
| `flexbox-grid` | Flexbox & Grid | `display: flex`, `display: grid`, `gap`, `grid-template-columns` |
| `grid-responsivo` | Grid Responsivo | `auto-fit`, `minmax()`, breakpoints, `repeat()` |
| `mediaquery` | Media Queries | `@media`, breakpoints mobile-first, `orientation` |
| `pseudo-classes` | Pseudo-classes | `:hover`, `:focus`, `:first-child`, `:nth-child()`, `:not()` |
| `pseudo-elements` | Pseudo-elements | `::before`, `::after`, `::first-letter`, `::selection` |
| `background` | Background CSS | `background-image`, `gradient`, `background-size`, `position` |
| `display-ex` | Display | `block`, `inline`, `inline-block`, `none`, `flex`, `grid` |
| `listas` | Listas | `list-style`, `::marker`, reset CSS, listas customizadas |
| `object-fit` | Object-fit | `cover`, `contain`, `fill`, `scale-down`, `none` |
| `pontos-referencia` | Transform Origin | `transform-origin`, rotação, escala, animações |
| `tipografia` | Tipografia | `font-family`, `font-weight`, `line-height`, `font-size`, variáveis CSS |
| `unidades/em-rem` | Unidades Relativas | `rem` vs `em`, `clamp()`, tipografia fluida |
| `unidades/vh-vw` | Unidades Viewport | `vh`, `vw`, `vmin`, `vmax`, altura total da tela |

## Como Visualizar os Exercícios

**Opção 1: Abrir diretamente no navegador**
- Clique duas vezes no arquivo `.html` desejado dentro de cada pasta

**Opção 2: VS Code + Live Server (recomendado)**
1. Instale a extensão **"Live Server"**
2. Clique com botão direito no arquivo `.html` → **"Open with Live Server"**

## Conceitos Abordados no Curso

- HTML Semântico (`header`, `nav`, `main`, `article`, `section`, `footer`)
- CSS Reset & Normalize
- Box Model & Display
- Flexbox (alinhamento, distribuição, ordenação)
- CSS Grid (template areas, auto-fit, minmax)
- Design Responsivo (Mobile-first, breakpoints)
- Pseudo-classes & Pseudo-elements
- Tipografia & Variáveis CSS
- Unidades Relativas (`rem`, `em`, `vh`, `vw`, `clamp`)
- Backgrounds, Gradientes, Imagens
- Transform & Transform-origin
- Object-fit para imagens responsivas
